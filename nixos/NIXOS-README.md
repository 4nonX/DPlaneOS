# DPlaneOS on NixOS: Technical Reference

DPlaneOS is a NixOS appliance. Every part of the NAS state is either built declaratively (NixOS), snapshotted (ZFS), or recorded in the configuration history (and optionally in Git):

| Layer | Technology | Going back |
|-------|-----------|------------|
| System | NixOS generations | the previous generation, at boot or by command |
| Data | ZFS | snapshots and rollback |
| Configuration | DPlaneOS change history, optional Git repository | any earlier configuration (System › Change History) |

How to install: [Installation Guide](../docs/admin/INSTALLATION-GUIDE.md) (installer ISO) or the [Live Boot Quick Start](../docs/admin/LIVE-BOOT-QUICKSTART.md). Overview of the files: [README.md](README.md).

## How an installed system is built

The installed system is built from **`/etc/nixos/flake.nix`**. The daemon writes it (and keeps it in step with the installed release):

- the DPlaneOS release it was installed or updated from (`github:4nonX/DPlaneOS/v<version>`),
- `/etc/nixos/hardware-configuration.nix`, generated by the installer,
- `/etc/nixos/local.nix`, if it exists: your own NixOS settings.

`/etc/nixos/configuration.nix` only throws an error that points to the flake: a rebuild without it would install plain NixOS. A manual rebuild is

```bash
sudo nixos-rebuild switch --flake /etc/nixos#dplaneos --impure
```

Normally you never run it: the Updates page builds the next release, reboots into it, checks it and rolls back if the check fails. See [Updates](../docs/admin/OTA-UPDATES.md).

### Your own NixOS settings

Put them in `/etc/nixos/local.nix`, a NixOS module:

```nix
{ pkgs, ... }: {
  environment.systemPackages = [ pkgs.htop ];
}
```

They are part of every later build, including updates.

## Going back

```bash
sudo nixos-rebuild switch --rollback   # the previous generation, now and at boot
```

If the system does not boot, choose an older generation in the systemd-boot menu. After going back to an older release by hand, also set that release in `/etc/nixos/flake.nix`, or the next rebuild builds the newer one again; see [Updates › Going back by hand](../docs/admin/OTA-UPDATES.md#going-back-by-hand).

## The disk and `/persist`

The system disk has three partitions (`disko.nix`): the ESP (`/boot`, 512 MB), the system partition (`/`, ext4, with the Nix store and the generations) and `/persist` (ext4, the rest). Data disks are never touched by the installer.

`/persist` holds the state: the database, the daemon's keys and settings, SSH host keys, the machine ID, the ZFS host ID, Samba's state and the logs. It is bound into place at boot (`impermanence.nix`). Each machine creates its own ZFS host ID once (`/persist/etc/hostid`), so that ZFS multihost and the protection against a second import of a shared pool work.

The daemon also writes a configuration backup once a day to the first data pool (`<pool>/.dplaneos-config/`, the newest 14). After losing the system disk: reinstall, import the pool, and restore under Settings › Maintenance.

## What the appliance includes

- **ZFS** - OpenZFS 2.4, monthly scrub, snapshot schedules set in the web interface, ZED events to the daemon
- **Samba**, **NFS** - shares managed by the daemon
- **Docker** - overlay2, weekly prune of unused images; starts after the pools are online (`dplaneos-zfs-gate`)
- **S.M.A.R.T.** - disk health and scheduled tests
- **Avahi** - `<hostname>.local` (`dplaneos.local` by default)
- **nginx** - the web interface and the API (WebSocket connections up to 24 hours)
- **PostgreSQL 17** - the node's database
- **Firewall** - on; see the [Installation Guide](../docs/admin/INSTALLATION-GUIDE.md#firewall)
- **Recovery CLI** - `sudo dplaneos-recovery`: status, services, database, password reset, two-factor authentication, pools, network, UPS, logs (a configuration backup is restored with `dplaned -recover-restore`; see the [Recovery Guide](../docs/admin/RECOVERY.md))
- **Removable media** - USB devices listed, mounted and ejected from the web interface

## Why NixOS for a NAS?

- **Atomic updates**: a new release is a new generation; the running one is not changed in place.
- **Generations**: every build stays bootable until it is garbage-collected (after 14 days; the boot menu shows the two newest).
- **Reproducible**: the same release gives the same system on every machine.
- **No drift**: the system is what the flake describes.

How DPlaneOS uses each NixOS primitive: [NIXOS-RATIONALE.md](../docs/reference/NIXOS-RATIONALE.md).
